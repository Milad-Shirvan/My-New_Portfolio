Lofi Music Player

A personal React project: a calm, glassmorphism music player built to sharpen my component and state skills.

RoleSolo build
TypePersonal project
Year2025
StackReact · JS · CSS
View live demo ↗
Overview

A lofi music player with a soft, glassmorphism interface, made for playing relaxed tracks in a calm, focused space.

I built it as a personal project to get more comfortable with React fundamentals, handling audio playback, and translating a specific visual style into a real, interactive interface.

The challenge

Two things to get right: managing audio state (play, pause, track changes) cleanly in React without the UI drifting out of sync, and pulling off the glassmorphism look, with its blur and transparency, so it felt polished rather than muddy.

What I built
  1. 01

    Audio player in React

    Built the playback controls and track handling with React state, keeping the interface in sync with what is actually playing.

  2. 02

    Glassmorphism UI

    Recreated the frosted-glass aesthetic with layered blur, transparency and soft lighting for a calm, modern feel.

  3. 03

    Component structure

    Broke the interface into reusable components to keep the code tidy and easy to extend.

Outcome

A small but complete player that does one thing nicely, and a project that made React state and styling click for me in a way tutorials alone had not.

Note to self: add anything you would improve next, for example a playlist, keyboard controls or a visualiser. Showing what you would do next reads well to interviewers.
